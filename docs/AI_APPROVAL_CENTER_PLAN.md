# 세왕 AI 승인센터 — 1차 구현 작업

상태: 개발 브랜치 초기화 (운영 배포 없음)
원칙: 기존 index.html 및 발행 파일 수정 금지, 운영 데이터 읽기 전용, 외부 발행은 대표 승인 필수.

## 확인된 현재 구조
- 기존 저장소는 루트 index.html 기반 정적 주간 리포트 센터.
- 루트 package.json 및 vercel.json은 현재 경로에서 발견되지 않음.
- 따라서 기존 정적 사이트에 관리자 API를 직접 덧붙이지 않는다.
- 승인센터는 별도 인증된 애플리케이션/API와 영속 DB가 필요하다.

## 업무 상태
RESEARCHING → DRAFTING → IN_REVIEW → PENDING_APPROVAL → APPROVED → PUBLISHING → PUBLISHED
반려: CHANGES_REQUESTED → DRAFTING
오류: FAILED, 보류: ON_HOLD

## 보안 및 데이터 규칙
1. 보고서, 기사, 기사 버전, 출처, 이미지 권리, 승인, 감사 로그, 발행 작업을 별도 테이블로 보관.
2. 승인 시 보고서 버전과 콘텐츠 SHA-256을 고정. 이후 수정하면 승인 무효.
3. 서버에서 역할 기반 권한 및 최신 버전 검증. 클라이언트 체크박스만으로 승인하지 않음.
4. 발행은 별도 권한의 작업자가 승인된 해시만 대상으로 실행. idempotency key로 중복 방지.
5. 기존 리포트 저장소에는 검증된 결과물을 PR로 제안하며 자동 main push 금지.
6. API 키·개인정보·영업 내부정보를 정적 HTML 또는 공개 저장소에 포함하지 않음.
